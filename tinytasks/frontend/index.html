Docker 101 (quick)

  • Image: the template; built from a Dockerfile.
  • Container: a running instance of an image.
  • Compose: runs multi-service apps (db+api+ui).
  • Why Docker? Same app, same deps, any host.

Pipeline: Dockerfile → build image → run container → healthcheck → logs
